# Cidade Viva — 0.1.0

- Projeto Android em Java 17 + libGDX.
- Mapa isométrico 48 x 48 com terrenos, ruas e zoneamento.
- Simulação econômica, população e salvamento local.
- Build de testes: GitHub Actions (`.github/workflows/android-apk.yml`).
- Entregável: artefato ZIP contendo APK debug instalável no Android.
- Pendente: validar jogabilidade, desempenho e interface no dispositivo físico.
